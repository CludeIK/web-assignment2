# Assignment 2: Advanced CSS (Flexbox & Grid)

## Description
This project is the second individual assignment for the **Web Technologies** course at Astana IT University. It demonstrates modern layout techniques using CSS Flexbox and CSS Grid without relying on floats.

## Structure
- **index.html:** Home page with navigation.
- **task1.html:** Flexbox Navigation Bar (Task 0) & Card Row with equal heights (Task 1).
- **task2.html:** Grid Layout Areas (Task 2) & Image Gallery with hover overlay (Task 3).
- **task4.html:** Portfolio page combining Flexbox and CSS Grid (Task 4).
